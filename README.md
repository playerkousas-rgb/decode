# Scout Decode ・ 密碼解碼助手

> 獨立解碼 Web App（第一期）。成員見到密文，打入去即刻試：凱撒位移（＋／− 與 0–25 全表）、反射 Atbash、倒序。
> 純前端、離線可用、唔使登入、冇後端。

## ⚠️ 同 CODE App 嘅關係（必讀）

- **Scout Decode 係完全獨立嘅 App**：自己一個 repo／一條 URL，同 Scout System「CODE」分開派發。
- **禁止**喺 CODE 側欄或導覽加任何通往 DECODE 嘅連結；CODE 嗰邊完全唔使改。
- 本 App 專為「對住紙／投影上嘅密文」現場解題而設，來源唔保證係本系統出嘅卷。

## 功能（第一期）

| 功能 | 說明 |
|---|---|
| 密文輸入 | 自動轉大寫，最多 200 字元；數字／空白／符號原樣保留 |
| 凱撒還原 | **純解碼**：明文 = 密文 − N（CODE 編碼用 +N）；大掃 ＋1／−1，可直接輸入 N |
| 0–25 暴力表 | 一次列 26 行（涵蓋晒所有方向），當前 N 高亮；點該行 = 設定該位移並捲到主結果 |
| 反射 Atbash | A↔Z、B↔Y……固定一組，無位移 |
| 倒序 | 整段字元反轉（含空白），轉大寫 |
| 複製 | 每張結果卡一鍵複製，Toast「已複製」 |
| 本機記憶 | localStorage 記草稿、上次 N；「清除」可刪走 |
| **查表解碼** | 摩斯（`. - /`）、電話 T9、座標 Grid（KEY 預設 SCOUT）、NATO 拼音 — 即時解碼，結果可⬆入主解碼區再試凱撒／反射／倒序 |
| **拍照解密（二期・實驗版）** | 見下方「拍照解密模組」 |

## 與 CODE App 完整對齊（10/10）

| CODE 類型 | DECODE 解法 |
|---|---|
| 凱撒 Caesar | 主解碼區：−N 還原＋0–25 全表 ✅ |
| 反射 Atbash | 主解碼區 ✅ |
| 倒序 Reverse | 主解碼區 ✅ |
| 摩斯 Morse | 查表：打 `. - /` ✅ ＋ 拍照自動辨識 ✅ |
| 電話 T9 | 查表：`22 43 33` 式輸入 ✅ |
| 座標 Grid | 查表：pair 輸入＋KEY（預設 SCOUT，可改）✅ |
| NATO | 查表：拼音詞輸入 ✅ |
| 旗號 Semaphore | 拍照：三下點位＋角度表（同 CODE 嘅 `SEM_ANGLES`）✅ |
| 點字 Braille | 拍照：自動辨識六點 ✅ |
| 朱高 Pigpen | 拍照：自動切符號＋圖表人手對照 ✅ |

外加：🅰 **印刷英文 OCR**（Tesseract.js，唯一要上網嘅功能）— 讀到嘅字可以⬆入任何解碼工具。

> 注意：CODE 嘅座標 Grid 暫時編唔到 **Z**（佢個 5×5 表少咗一格，Z 會原樣留低）；DECODE 已預埋 Z 格（KEY=SCOUT 時 `TT`→Z），就算手寫卷用足 25 格都解到。兩邊 I/J 共用。

> **v1.1 變更（2026-08-26，委託方指示）**：移除「當明文加密」模式。DECODE 只做解碼；加密一律用 Scout System CODE App。0–25 全表本身已涵蓋所有位移方向，解碼功能零損失。

## 拍照解密模組（第二期・實驗版）

委託方 2026-08-26 點頭落實第一批。全部**本機運算、零上傳、保持單檔離線**：

| 類型 | 模式 | 做法 |
|---|---|---|
| 📟 紙上摩斯 | **自動辨識** | Otsu 二值化 → 主行偵測 → 點／橫分類 → 間距推斷字母／詞；輸出 `. - /` raw＋解碼文字＋每符號信心，raw 可人手改即時重解 |
| ⠿ 印刷點字 | **自動辨識** | 圓點偵測 → 六點細胞聚類 → 標準點字表；輸出文字＋每細胞信心，可人手改 |
| 🔐 朱高 | **輔助對照** | 自動切割符號（連通元件＋外框合併）→ 逐個放大；用戶對照圖表㩒字母。**誠實標明唔係自動辨識** |
| 🚩 旗號火柴人（Semaphore） | **三下點位** | 喺相上點：①旗一 ②旗二 ③身體中心 → 計兩旗角度 → 查 SEM_ANGLES 表（與 CODE App 完全一致）→ top-3 候選＋信心％；角度表 26 字母唯一可辨（已測 ±10° 噪聲） |

規格要求全部達到：候選＋信心＋可人手改；**冇任何地方裝 100% 準**。

**未做（如需要另議）**：真人旗號相片／人像姿態辨識、電話 T9 以外嘅打字輸入方式。印刷英文 OCR 已於 v2.1 加入（要上網載入引擎）。

## 凱撒規則（與 CODE 對齊）

- 只動 A–Z，其他字元原樣保留。
- 位移 +N：明文字母 `+ N`（mod 26）= 密文。
- 解碼：密文 `− N`（等價於 `+ (26−N)`）。
- 固定範例（還原方向）：`KHOOR` −3 → `HELLO`；`HELLO` −23（≡+3）→ `KHOOR`；`ABC` −23（≡+3）→ `DEF`；`ABC` −3 → `XYZ`；`FGHIJ` −5 → `ABCDE`。

## 執行

單檔 `index.html`、零依賴：

- 直接用瀏覽器打開 `index.html`（離線可用）。
- 或本機起伺服器：`python3 -m http.server 8080` 或 `npx serve .`

## 部署成獨立 URL

1. 開一個新 repo（例如 `decode`），放入 `index.html`（成個資料夾抄過去就得）。
2. GitHub Pages：Settings → Pages → 由 main 分支 root 發布 → 得到獨立網址。
3. 派發時只俾呢條 DECODE URL；唔好喺 CODE 加任何入口。

## 部署（Vercel）與瘦身

- Vercel 自動偵測做**靜態網站（framework = Other）**，直接 serve 根目錄；輸出只有 `index.html`，**無需 `vercel.json`／`outputDirectory`**。
- `.vercelignore` 寫明只上傳網頁產物（排除 `.git`、`tests/`、README、暫存／備份檔等），防止儲存空間爆滿。
- 全 repo 上線部分只有約 72 KB；OCR 引擎行 CDN on-demand（釘死 `tesseract.js@5.1.1`），唔用唔會下載。
- 防增肥守則見 **`SLIMMING.md`** —— 每次改版前必讀。
